🔑 Firebase Authentication Setup

Where we left off — steps to wire up real login.

Step 1 — Firebase Project
Go to console.firebase.google.com → New Project → name it dynastyhq-app
Step 2 — Enable Authentication
Build → Authentication → Sign-in method → Enable Email/Password + Google
Step 3 — Firestore Database
Build → Firestore Database → Create database → Start in test mode first.
Collections needed: usersleaguesmembershipsnotificationsweeks
Step 4 — Roles via Custom Claims
Use Firebase Admin SDK (Cloud Function) to set customClaims: {'role': 'admin'} or 'commissioner' per user. This controls which pages render — the HTML checks the claim and shows/hides Admin, Commissioner, or Member views.
Step 5 — Notification Services
Push: Firebase Cloud Messaging (free) → service worker in sw.js
Email: SendGrid free tier (100/day) → Cloud Function triggers on new notification doc
SMS: Twilio → Cloud Function reads user phone from Firestore, sends via REST
Step 6 — Hosting
Run firebase init hosting → firebase deploy → live at dynastyhq-app.web.app for free.
